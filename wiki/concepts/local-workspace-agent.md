# Local Workspace Agent

- Type: concept
- Status: interpreted
- Source: [CONTEXT.md](../../CONTEXT.md), [ADR-0008](../../docs/adr/0008-local-workspace-agent-v1.md)
- Updated: 2026-08-13

## Facts

The accepted v1 contract covers isolated Markdown, CSV, and code workspaces, allowlisted tools, a frozen 30-task Evaluation Suite, and deterministic graders.

## Interpretation

The common workspace is the product seam: it enables several task families without redefining the product as a Coding Agent, Data Analysis Agent, or Research Agent.
