## Maintenance rhythm

- Ingest a source before relying on it for a design claim.
- Append one log entry for every material experiment, failure, or product decision.
- Run the Lint checklist before a release or resume evidence migration.
- Update links when a page moves; never rewrite old log entries to make a failed path disappear.
