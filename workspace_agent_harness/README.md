# Python package modules

- `__init__.py`: domain-neutral AgentLoop, General Agent Runtime, explicit Adapter configuration identities, per-run Pack/Adapter drift checks, canonical Pack/Suite fingerprints, process-isolated evaluator limits, workspace/Trace primitives, Runtime provenance, and Evaluation Campaign kernel.
- `proof_packs.py`: concrete `data-analysis` and `workspace-coding` seed Pack Adapters, fixtures, capability Adapters, scripted proof Model Adapter, deterministic evaluators, retained coding-test process evidence, and the explicitly non-publishable two-case development-smoke suite.
- `benchmarks.py`: deep benchmark-configuration Module for fail-closed PinchBench P0 catalog loading and composition of the 15+15 vertical catalog with the two implemented seeds.
- `react_mvp.py`: Phase 0 DeepSeek JSON Adapter, visible Act/ReAct treatment checks, bash-only Docker execution, bounded model observations, and lossless raw command artifacts. It reuses the existing `AgentLoop`; no SWE-bench result exists yet.
- `protocol_reliability.py`: protocol-reliability-v1 configuration/corpus loading, JSON and Strict request construction, raw HTTP transport, L0–L3 assessment, deterministic trace extraction, and Wilson intervals. It measures provider×protocol compliance; it does not execute benchmark tasks.
- `protocol_max_token_sensitivity.py`: content-hashed 2K/4K/8K sensitivity and separately versioned 16K extension loading, parent-artifact verification, deterministic slots, request equivalence, and returned-response marker diagnostics.
- `context_projection.py`: WorkOrder #7's semantic Context projection and WorkOrder #8's typed overflow-recovery projection attempt, with verified/fallback/unknown window provenance, sourced summary preservation, exact artifact retention, and no arbitrary truncation.
- `evented.py`: the evented `AgentLoop`, one-operation `ModelGateway`, typed settled/failed exchanges, one classified Context-overflow recovery, Runtime admission, Canonical History, deterministic demo Adapters, append-only `run-event/v1` log, compact/expanded/trace projections with field visibility enforcement, and zero-call replay.
- `behavioral_eval.py`: WorkOrder #9's frozen 12-case deterministic Domain Pack/campaign, typed local transitions, protected exact oracle, runtime-versus-task failure attribution, deterministic report, and zero-Gateway/tool reconstruction; pending independent review.
- `deepseek_live.py`: WorkOrder #11 Stage A's DeepSeek V4 Flash native-tool Translation/Gateway, restricted-reasoning carrier, exact secret-free exchange retention, and injected constructor-time-zero-I/O HTTP Adapter; no live call result is included.
- `deepseek_live_campaign.py`: WorkOrder #11 Stage A's paired 120-slot schedule, verified live Context policy, CNY/call/Token/identity budget stops, constructor-time-zero-I/O balance Adapter, zero-call inventory, and complete stopped-campaign reconstruction; pending independent review.
- `deepseek_live_runner.py`: WorkOrder #11 Stage A-R's independently accepted single production campaign seam: exact identity acknowledgement, serial slot ownership, pre-dispatch intent/authorization, mandatory post-attempt settlement, explicit stop/incomplete denominator states, and zero-Adapter reconstruction. Stage A-R itself made no live calls; the later accepted v2 Stage B terminal Evidence is indexed at [`../docs/evidence/deepseek-live-stage-b-terminal-2026-08-29.md`](../docs/evidence/deepseek-live-stage-b-terminal-2026-08-29.md), and v2 cannot be resumed.
- `tui.py`: consumer-only Python terminal entry for non-blank Unicode task input, Ctrl-C cancellation, proactive compaction and successful/exhausted overflow demos, repeatable compact/expanded/trace selection over one retained sequence, and replay; it contains no live Provider lifecycle or alternate transcript.
- `benchmark_configs/`: shipped PinchBench source locks, the original 30-case vertical catalog, the frozen five-case ReAct development smoke, protocol-reliability-v1 locks, maximum-token sensitivity locks, WorkOrder #9's deterministic 12-case manifest, and WorkOrder #11 Stage A's paired 120-slot DeepSeek zero-call lock. These are configuration artifacts, not external benchmark results.

The Runtime Module does not import `proof_packs.py`, `benchmarks.py`, `react_mvp.py`, `protocol_reliability.py`, or `protocol_max_token_sensitivity.py`. Composition code and integration tests may depend on them; adding a third Pack remains outside the current Gate.
