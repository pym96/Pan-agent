# ADR-0008: Make Local Workspace Agent the v1 product

- Status: Accepted
- Date: 2026-08-13

The repository keeps its Git history but changes from an autonomous-research product to **Workspace Agent Harness**, a general Local Workspace Agent for Markdown, CSV, and code tasks. This is the only v1 product because it supplies an end-to-end scenario for Agent Harness, Evaluation, Trace, recovery, and reliability evidence within the eight-week job-search window; Coze is only a Product Reference, the frozen 30-task Evaluation Suite is the acceptance mechanism, Terminal-Bench is conditional on v1 completion, and GAIA, new 3DV work, model training, and a precommitted paper are excluded.

ADR-0001 and ADR-0007 remain historical records of the previous research-product boundary; this decision supersedes their product identity and application-selection language while preserving the reusable bounded loop, Trace, budget, policy, recovery, and evaluation design.
