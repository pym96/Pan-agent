Task commands inherit an explicit task environment from a public image, never the controller's credential environment. The finite isolation claim excludes hostile in-process controller Python and universal kernel escapes.

This is official scoring under restricted deployment, not the upstream default CLI environment. The facade is an API boundary around trusted pinned code, not a sandbox for arbitrary malicious Python reflection.
