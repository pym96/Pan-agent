# v0.1.5 — real-time Markdown demonstration

A 29-second original-speed recording shows the normal installed Pan CLI rendering a real Kimi response as it arrives. The run uses ordinary configuration, one text-only prompt and zero tools. No fixture provider, replay or artificial token pacing is used.

Markdown is already built into **v0.1.4**. Install that unchanged package using README; configure your API credential and start the TUI normally. This release adds video, Chinese subtitles and documentation, not a new runtime package.

Download `pan-agent-markdown-live.mp4`, `pan-agent-markdown-live.srt` and `SHA256SUMS`. [Recording and supported scope](https://github.com/pym96/Pan-agent/blob/v0.1.5/docs/demo/tui-release56/MARKDOWN-LIVE.md). Existing offline examples and all prior releases remain available and clearly labeled.
