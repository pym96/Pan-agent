# Installed offline consumer walkthrough

See [user guide](../../docs/demo/consumer-readiness/README.md) for build/install/run commands and expected outcomes. `walkthrough.mjs` invokes an already installed CLI with the existing `--fixture` option. Its sibling network guard observes and denies Node network entry points; it does not inject responses or change product code. Inputs are pre-existing synthetic artifacts, never model task-solving evidence. Node >=22.19.0, POSIX shell/ps; no Python dependency. All outputs go to the required new directory outside this script directory.
