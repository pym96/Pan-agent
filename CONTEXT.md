# Autonomous Research Harness

This repository builds a system that can execute long-running research experiments under explicit safety and evaluation controls.

## Language

**Autonomous Research Harness**

The only primary product: a replayable, recoverable, evaluable runtime and experiment system for autonomous research agents.

_Avoid_: coding-agent clone, automatic paper generator, geometry-paper project

**Coding Benchmark**

A set of automatically judged programming tasks used to validate early Harness reliability. It is a proving ground, not the final product.

_Avoid_: main product, final benchmark

**AutoGeoResearch**

The first real Research Application, intended to test whether the Harness can propose, execute, and reproduce geometry experiments. Its baseline, dataset, and evaluator are selected through an explicit qualification step.

_Avoid_: second primary product, automatic paper writer

**Research Application**

A domain-specific workspace connected to the Harness through an allowlist, fixed commands, an immutable evaluator, and an experiment schema. AutoGeoResearch is the first instance.

_Avoid_: arbitrary repository, unrestricted shell environment

**Research Outcome**

A result produced by the Harness and verified by reproduction. A paper may communicate a Research Outcome, but publication is not required for project success.

_Avoid_: generated paper, guaranteed publishable result

**Research Task**

The operator-authored objective, workspace policy, evaluator reference, budgets, and stopping rules that define one research campaign.

_Avoid_: free-form prompt with unrestricted authority

**Research Run**

One bounded execution of a Research Task, producing an append-only Event Log, zero or more Experiment Attempts, and exactly one terminal RunResult.

_Avoid_: endless loop, chat session

**Experiment Attempt**

Any candidate experiment formally started by the Harness. Successful, rejected, crashed, timed-out, and interrupted attempts all count.

_Avoid_: quick try, disposable run

**Auditable Attempt**

An Experiment Attempt with its hypothesis, code version, configuration, logs, resource usage, terminal status, and disposition completely recorded. Crashes, OOMs, and timeouts can still be Auditable Attempts.

_Avoid_: successful experiment, improved result

**Auditable Attempt Rate**

The fraction of Experiment Attempts that are Auditable Attempts. The v1 target is 100%.

_Avoid_: completion rate

**Valid Experiment**

An Experiment Attempt with a preregistered hypothesis, isolated code version, agent-immutable evaluation, complete provenance, explicit disposition, and a result reproducible within declared tolerances.

_Avoid_: ran successfully, metric screenshot, cherry-picked result

**Valid Experiment Rate**

The fraction of Experiment Attempts that become Valid Experiments. The v1 target is at least 80% across the acceptance campaign.

_Avoid_: paper success rate, improvement rate

**Improvement Rate**

The fraction of Valid Experiments that improve on the current baseline. It is reported without a minimum target.

_Avoid_: project success rate

**Unattended Research Run**

An eight-hour Research Run that requires no human code edits, restarts, or answers after launch and stops safely because of predefined time, request, cost, or experiment budgets. An emergency stop remains available.

_Avoid_: endless loop, unsupervised arbitrary execution

**Research Operator**

The single user who configures the local code, compute, model service, policies, and Research Tasks, then starts, observes, interrupts, and reproduces runs.

_Avoid_: tenant, hosted-platform customer

**Local Research Workspace**

The operator-controlled local environment containing research repositories, isolated worktrees, GPUs, and credentials. v1 does not turn it into a hosted service.

_Avoid_: SaaS workspace, shared tenant environment

**Patch Proposal**

A candidate code change generated by the agent for explicitly allowlisted research files. It must pass policy checks before execution.

_Avoid_: arbitrary code execution, host modification

**Isolated Executor**

The component that applies a Patch Proposal in a temporary Git worktree and invokes only predefined setup, test, train, and evaluation commands in a constrained environment.

_Avoid_: agent shell, host terminal

**Protected Control Plane**

Harness code, evaluator code, data splits, budgets, credentials, policies, and launch rules that the research agent cannot modify and should not receive unless required.

_Avoid_: research code, agent context

**Protected Prior Work**

Unpublished or anonymously reviewed research assets excluded from agent context, Research Applications, public artifacts, and Patch Proposals.

_Avoid_: public baseline, modifiable research code

**Policy Blocked**

The terminal status of an Experiment Attempt whose requested patch or action exceeds its declared boundary. During unattended operation it is recorded and resolved without waiting for human approval.

_Avoid_: crash, human approval queue

**Provider Qualification Gate**

A deterministic preflight suite that a model configuration must pass before it may drive a long or costly Research Run. It checks protocol compatibility, tool use, structured output, cancellation, accounting, and representative task behavior.

_Avoid_: provider marketing benchmark, model leaderboard

**Content Release**

Public material derived from a completed, verified engineering milestone. It is a release artifact, not a parallel content project.

_Avoid_: content-first feature, posting quota
